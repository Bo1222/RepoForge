## 第一份：Agent / LLM 匿名示例

原模板将岗位定位、责任范围、机制、评测口径和公开证据放在前面。README 明确说明它不是个人经历复刻，所有 X/Y 都要用实际证据替换。

### 项目段 1：Long-Horizon Agent Harness

**项目介绍概括：**针对多步骤任务中的上下文膨胀、错误累积和恢复困难，组织可插拔 runtime，列举按需 Skill、子 Agent 调度、沙箱与持久化 checkpoint；再用工具调用缺失配对、循环调用和超时等失败类型说明验证与恢复机制。

**写法：**问题与职责 → 关键机制 → 失败边界 → 代码、配置、轨迹和复现材料。

**指标性质：**成功率、上下文占用、Star、贡献者与下游集成数均为占位符，不能当作作者实测。

### 项目段 2：Agent Trajectory Pipeline for SFT / RL

**项目介绍概括：**围绕轨迹同质化和困难任务的重复推理成本，设计生成、执行、评测、清洗和导出流水线；用多模型/scaffold、断点续跑、失败报告回注及规则与 LLM judge 评分说明数据闭环，并提出首次错误决策定位。

**写法：**数据问题 → 流水线 → 质量评估 → 每条有效轨迹的成本与消融。

**指标性质：**轨迹数、有效样本占比、成本和 benchmark 提升均为占位，不能据标题推断已经完成 SFT/RL 训练。

### 项目段 3：业务数据分析 Agent

**项目介绍概括：**面向运营、产品和研发的数据查询、归因分析及报告生成，以意图路由和 schema 驱动的工具注册组织流程，对工具输出做摘要和滑动截断，再用时延、返工率、留存及单任务成本描述验收维度。

**写法：**使用者与任务 → 工具链与上下文处理 → 业务结果与系统成本。

**指标性质：**调用量、完成率、耗时、留存等均为 X/Y 占位，不能复用为个人项目成绩。

## 第二份：大模型算法占位符模板

该模板含科研、算法实习及两个项目段。科研与实习中的名校、公司、论文和荣誉属于模板内容，本调研只提取项目表达，不将其归为作者履历。

### 项目段 4：基于自我纠错机制的智能 RAG 检索系统

**项目介绍概括：**针对知识库召回不足，在低置信度时触发反思和查询改写，组合向量、BM25 与混合检索，再加入交叉编码器重排；用消融拆分各机制的贡献。

**写法：**初始错误类型 → 迭代检索机制 → 检索策略融合 → 重排 → 分项验证。

**指标性质：**召回率、平均轮次和满意度均为占位；模板中的生产应用句不构成真实上线证据。

### 项目段 5：基于分层记忆架构的长程对话 Agent 系统

**项目介绍概括：**围绕长对话遗忘划分工作记忆、短期摘要和长期记忆，分别保留近期完整交互、提取近期要点，并按重要性与时间衰减保存长期信息；配合混合检索、压缩和冲突更新支持持续交互。

**写法：**遗忘问题 → 分层职责 → 召回与更新 → 长对话任务验证。

**指标性质：**保留率、检索速度和任务完成率均为占位。
